# SHAMS_Gyro
Our project aims to develop an innovative gyroscopic inclinometer system. The device is engineered to high-accurately measure borehole azimuth relative to the true geographic North and determine its inclination angle. This high-tech equipment serves as a critical technological solution for the mining, exploration, and geological sectors.
