# ShAMS_Gyro
Mening g’oyam giroskopli Inklinometr yaratishdan iborat. Bu uskunaning vazifasi burg’ilash quduqlarining Geografik qutbga nisbatan azimut yo’nalishini va vertical yoki gorizontal tekislikka nisbatan og’ish burchagini aniqlashdan iborat. Ushbu uskuna tog’-kon sanoati va geologiya sohasida ishlatiladi.
